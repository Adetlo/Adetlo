## About

I have spent more than a decade in banking technology, moving from core banking analysis and application support through engineering and management roles to heading the IT function of an international bank's London branch.

My work sits at the intersection of five disciplines that rarely overlap in one person:

- **Banking domain** — core banking, payments, treasury, reconciliation, financial reporting
- **Software engineering** — building and integrating the systems banks actually run on
- **Data & AI** — data engineering, analytics, and applied machine learning in financial services
- **Security** — identity and access management, secure platform design, regulatory expectations
- **Technology leadership** — running IT for a regulated banking entity end to end

That combination means I can take a financial product from business requirement to running, secured, auditable software — and lead the team that keeps it that way.
